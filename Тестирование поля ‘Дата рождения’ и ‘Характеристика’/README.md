# Тестирование поля "Дата рождения" и "Характеристика" (Тестовое задание "Знаки Зодиака")

## Описание проекта
Данный проект представляет собой детальную проработку тестовых сценариев для двух ключевых полей ввода в рамках тестового задания: "Дата рождения" и "Характеристика" (генерируемый текст на основе даты и знака зодиака). Была применена строгая **приоритезация тестов** (High, Medium, Low) для эффективного покрытия.

## Проектирование тестов для поля "Дата рождения"

## Проектирование тестов для поля "Характеристика" и кнопки "Выполнить"

### 1. Поле "Характеристика" (генерируемый текст)
*   **Класс эквивалентности:** Соответствие генерируемого текста введенным данным.
*   **Тестирование:**
    *   **Все обязательные поля заполнены верно:** Дата рождения и знак зодиака корректны.
    *   **Обязательные поля не заполнены:** Проверка реакции при пустых полях (дата, знак, оба).
    *   **Поля заполнены неверно:** Некорректная дата, некорректный знак зодиака, неверные оба поля.
    *   **Конфликт Знака и Даты:** Введено валидное, но несовпадающее значение знака и даты (например: Дата = Рыбы, Знак = Лев).
    *   **Допустимое количество символов:** Min 1 символ, максимальная технологическая граница, пустое поле.
    *   **Допустимые символы:** Тестирование разных наборов символов (кириллица, латиница, спецсимволы, эмоджи, другие алфавиты).

### 2. Кнопка "Выполнить"
*   **Класс эквивалентности:** Функциональное состояние и взаимодействие.
*   **Тестирование:**
    *   **Функциональное состояние:** Кнопка активна (все поля валидны), неактивна/заблокирована (обязательное поле пустое).
    *   **Сценарий действия:** Однократное нажатие (переход к результату), нажатие по всей площади кнопки, многократное нажатие.
    *   **Связь:** Активация кнопки при некорректных, но валидных данных; повторное нажатие после успешного выполнения.
    *   **UI:** Проверка, что нажатие на пространство возле кнопки не вызывает действия.
