# Комплексное тестирование веб-платформы (имитация E-commerce / Steam Store)

## Описание проекта
Целью данного проекта было отработка навыков функционального и нефункционального тестирования на примере сложной веб-платформы, имитирующей функционал интернет-магазина (E-commerce) и магазина игр (Steam Store). Проект позволил применить и закрепить знания в области тест-дизайна, анализа требований, API-тестирования и отчетности.

## Демонстрация навыков
### 1. Анализ требований и декомпозиция
*   Проведен анализ функционала платформы по компонентам: Поиск, Информация об игре, Корзина, Список желаемого, Аккаунт, Профиль, Новости, Коммуникации, Производительность, Совместимость, Безопасность.
*   Сложные продукты декомпозированы на тестируемые модули для построения комплексных тест-стратегий.

### 2. Тест-дизайн и разработка тестовой документации
*   **Тест-кейсы:** Разработано **66 детализированных тест-кейсов** (TS\_*), охватывающих ключевые сценарии.
    *   [Ссылка на папку с тест-кейсами поиска (Excel/PDF)](ссылка/на/файл/test_cases_search.xlsx)
    *   [Ссылка на папку с тест-кейсами покупок (Excel/PDF)](ссылка/на/файл/test_cases_shop.xlsx)
*   **Чек-листы:** Создано 5 чек-листов (CL\_*) для систематизации проверок (например, `CL_REG_CORE`, `CL_SEARCH`, `CL_NONFUNC_CRIT`).
    *   [Ссылка на папку с чек-листами (Excel/PDF)](ссылка/на/файл/checklists.xlsx)
*   **Приоритизация и статусы:** Тест-кейсы снабжены приоритетами (High, Medium, Low) и статусами выполнения (Passed, Failed, NA), что отражено в итоговой статистике.

### 3. Функциональное тестирование
*   Успешно протестирована основная функциональность платформы.
*   **Результат:** Выявлено **10 дефектов** (2 критических, 8 средних).

### 4. Нефункциональное тестирование
*   **Производительность:**
    *   Замерено время загрузки главной страницы: **< 5 секунд**.
    *   Замерено время TTFB для поиска: **< 300 мс**.
*   **Совместимость:** Проведено тестирование на разных браузерах (Chrome, Firefox) и разрешениях экрана.
*   **Безопасность:** Тестированы базовые уязвимости (SQL-инъекции, XSS, валидация платежных данных, защита паролей) на основе **OWASP Top 10**.

### 5. Аналитика тестирования
*   Созданы диаграммы и статистики (распределение тестов по статусам, приоритетам, компонентам, журнал выполнения), демонстрирующие понимание метрик качества.
    *   [Ссылка на файл со статистикой и диаграммами (Excel/PDF)](ссылка/на/файл/testing_statistics.xlsx)

### 6. Поиск и документирование дефектов
*   Найдены 8 средних дефектов и 2 критических дефекта (например, проблема с оплатой **TS\_SHOP\_004**).
*   Все дефекты документированы с указанием шагов воспроизведения, текущего/ожидаемого результата.
    *   https://bugtracker.zoho.eu/portal/kononovanastya414gmaildotcom#zp/projects/316948000000057781/issue-detail/316948000000057929
