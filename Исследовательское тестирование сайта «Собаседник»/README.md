# Исследовательское тестирование веб-сайта “Собаседник”

## Цель проекта
Применение навыков исследовательского тестирования, поиска визуальных и логических дефектов, анализа юзабилити на реальном веб-ресурсе [Собаседник](https://guru.qahacking.ru).

## Описание
В рамках данного проекта было проведено углубленное исследование пользовательского интерфейса и функциональности веб-сайта "Собаседник" без заранее подготовленных тест-кейсов. Основное внимание уделялось поиску дефектов, влияющих на пользовательский опыт, визуальное восприятие и корректность работы приложения.

## Результаты: Выявленные дефекты
Было выявлено **более 20 дефектов**, классифицированных по следующим категориям:

### 1. Верстка и отображение (UI/UX)
*   Некорректное отображение контента: обрезаны фото, наложение элементов.
*   Неработающие изображения (отсутствие или битые ссылки на картинки).
*   Ошибки в верстке виджетов: разделы "Популярное", "О нас", "Главная страница" (например, "Популярное" вместо "Популярное" в заголовке).
*   Нарушение верстки в виджете "Популярное".

### 2. Функциональные ошибки
*   Некликабельные элементы (блоки новостей, кнопки).
*   Некорректные переходы по ссылкам (например, переход на "Говорящие кошки" вместо нужной статьи).
*   Ошибки в формах:
    *   Форма рассылки ("Спросите нас о собачках"): неактивна кнопка "Отправить", использует редирект (303) вместо прямого ответа, нет обратной связи после подписки.
    *   Форма бронирования питомца: неактивное поле "Особые пожелания", неактивное поле выбора "Выбор города", принимает некорректные форматы даты, активируется неверный элемент при выборе языка.
    *   Форма "Адрес": некорректные ограничения ввода (цифры вместо букв в имени/фамилии, избыточная длина телефона), разрешен ввод буквы в почтовый индекс.
    *   Добавление товаров в корзину: товары со статусом "Нет в наличии" добавляются.
*   Нерабочие кнопки ("Подтвердить отправку" в форме бронирования).
*   Проблемы с валидацией полей (например, в поле "Телефон" разрешен ввод более 12 символов).
*   Дублирование/лишние поля при оформлении заказа.
*   Внутренняя ошибка сессии (-2147483572) при отправке формы бронирования.
*   Ошибка "Could not instantiate mail function" при оформлении заказа.

### 3. Проблемы с контентом и локализацией
*   Ошибки в тексте (опечатки, неверное словоупотребление).
*   Неработающие ссылки или ссылки, ведущие на нерелевантный контент.
*   Ссылки, отображающиеся на английском языке ("Все новости").
*   Дублирование новостей.
*   Некорректное сообщение об ошибке ("Error quantity").
*   Нерелевантные ссылки в футере (на жизнь в Испании).

### 4. Юзабилити
*   Непонятные или отсутствующие сообщения об ошибках.
*   Нелогичные действия пользователя (например, при нажатии на язык меняется выбор собачьей породы).
*   Невидимые или неактивные кнопки.
*   Неинформативная обратная связь после выполнения действий.
