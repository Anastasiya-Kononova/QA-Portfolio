# Сегментация сети и настройка межсетевого взаимодействия (Тестовое задание)

## Описание проекта
Данный проект демонстрирует практическое применение навыков в области сетевых технологий для построения безопасной и сегментированной сети. Задание включало настройку IP-адресации, VLAN, маршрутизацию между сетями и управление трафиком с помощью `iptables`.

## Ключевые задачи и решения

### 1. Сегментация сети с использованием VLAN
*   **Задача:** Изолировать трафик между сетями N2 и N3, используя VLAN.
*   **Решение:**
    *   Подсеть `/28` была разделена на две меньшие подсети `/29` для каждого VLAN.
    *   **VLAN 10 для N2:**
        *   Диапазон: `192.168.2.16/29`
        *   Сетевой адрес: `192.168.2.16`
        *   Шлюз R1: `192.168.2.17`
        *   IP N2: `192.168.2.18`
    *   **VLAN 20 для N3:**
        *   Диапазон: `192.168.2.24/29`
        *   Сетевой адрес: `192.168.2.24`
        *   Шлюз R1: `192.168.2.26`
        *   IP N3: `192.168.2.26`

### 2. Конфигурация коммутатора (Switch 1)
*   **Задача:** Настроить порты для принадлежности к VLAN и пропуск тегированного трафика.
*   **Решение (пример Cisco-подобный):**
    *   Создание VLAN: `vlan 10`, `vlan 20`.
    *   Назначение Access Port для N2 (VLAN 10): `interface FastEthernet0/1`, `switchport mode access`, `switchport access vlan 10`.
    *   Назначение Access Port для N3 (VLAN 20): `interface FastEthernet0/2`, `switchport mode access`, `switchport access vlan 20`.
    *   Настройка Trunk Port для R1: `interface GigabitEthernet0/1`, `switchport mode trunk`, `switchport trunk allowed vlan 10,20`.

### 3. Конфигурация маршрутизатора R1 (Router-on-a-Stick)
*   **Задача:** Обеспечить маршрутизацию между VLAN через R1, выполняя "декапсуляцию" тегов.
*   **Решение (Debian-based):**
    *   Установка `vlan` пакета: `apt update && apt install vlan`.
    *   **Суб-интерфейс для VLAN 10 (N2):**
        *   Создание: `vconfig add eth1 10`
        *   Активация: `ip link set eth1.10 up`
        *   Назначение IP: `ip addr add 192.168.2.17/29 dev eth1.10`
    *   **Суб-интерфейс для VLAN 20 (N3):**
        *   Создание: `vconfig add eth1 20`
        *   Активация: `ip link set eth1.20 up`
        *   Назначение IP: `ip addr add 192.168.2.26/29 dev eth1.20`

### 4. Настройка правил межсетевого экрана (`iptables`)
*   **Задача:** Управлять трафиком между сетями N1, N4, N2 (VLAN 10), N3 (VLAN 20) и серверами.
*   **Решение:**
    *   **Запрет N1 → N4:**
        ```bash
        iptables -A FORWARD -s 192.168.0.0/21 -d 172.16.31.128/25 -j DROP
        ```
    *   **Разрешение N4 → N2/N3 (Прямой трафик):**
        ```bash
        # Разрешить N4 -> N2 (VLAN 10)
        iptables -A FORWARD -s 172.16.31.137/32 -d 192.168.2.16/29 -j ACCEPT
        # Разрешить N4 -> N3 (VLAN 20)
        iptables -A FORWARD -s 172.16.31.137/32 -d 192.168.2.24/29 -j ACCEPT
        ```
    *   **Разрешение N2/N3 → N4 (Обратный трафик):**
        ```bash
        # Разрешить N2 (VLAN 10) -> N4
        iptables -A FORWARD -s 192.168.2.16/29 -d 172.16.31.137/32 -j ACCEPT
        # Разрешить N3 (VLAN 20) -> N4
        iptables -A FORWARD -s 192.168.2.24/29 -d 172.16.31.137/32 -j ACCEPT
        ```
    *   **Примечание:** Понимание важности `/32` для точного указания хоста в правилах файрвола.

### 5. Другие сетевые настройки
*   **R2:** Настройка статического маршрута (`ip route add`), присвоение IP-адреса (`172.16.31.129/25`), разрешение трафика (`iptables -A FORWARD`).
*   **HTTP-Server / FTP-Server:** Назначение IP-адресов (`10.0.0.3/27`, `10.0.0.4/27`).
*   **R3:** Назначение IP-адресов (`13.14.171.2/30`, `10.0.0.1/27`). Настройка DNAT и правил `FORWARD` для доступа к серверам из Интернета. Маскировка исходящего трафика (`iptables –t nat -A POSTROUTING –o eth1 –j MASQUERADE`).

*   **Сетевое оборудование:** Коммутатор (Cisco-подобный синтаксис), Маршрутизатор (R1, R2, R3).

*   **Протоколы:** HTTP, FTP, TCP/IP.
