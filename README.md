## Мои Проекты

В этом репозитории представлены следующие проекты:

### 1. Комплексное тестирование веб-платформы (имитация E-commerce / Steam Store)
*   **Описание:** Отработка навыков функционального и нефункционального тестирования на примере сложной платформы.
*   **Ключевые результаты:** Разработка тест-документации (66 тест-кейсов, 5 чек-листов), выявление 10 дефектов (2 критических), нефункциональное тестирование (производительность, совместимость, безопасность OWASP Top 10), API-тестирование (Postman), создание аналитических отчетов.
*   **Навыки:** Комплексное тестирование, тест-дизайн, баг-репортинг, нефункциональное тестирование, API-тестирование, отчетность.
*   [Steam Store](https://github.com/Anastasiya-Kononova/QA-Portfolio/tree/c7b8a478279fb4bb4baa6a1916fab9d468918452/Комплексное%20тестирование%20веб-платформы).

### 2. Исследовательское тестирование сайта “Собаседник”
*   **Описание:** Применение навыков исследовательского тестирования, поиска визуальных и логических дефектов, анализа юзабилити на реальном веб-ресурсе.
*   **Ключевые результаты:** Выявлено и документировано более 20 дефектов (верстка, функциональные ошибки, проблемы контента/локализации, юзабилити).
*   **Навыки:** Исследовательское тестирование, поиск дефектов, анализ юзабилити, документирование багов.
*   [Собаседник](https://github.com/Anastasiya-Kononova/QA-Portfolio/tree/c7b8a478279fb4bb4baa6a1916fab9d468918452/Исследовательское%20тестирование%20сайта%20«Собаседник»).

### 3. Анализ требований к мобильному приложению
*   **Описание:** Детальный анализ требований и макета мобильного приложения на соответствие качественных требований (функциональные, нефункциональные, UI/UX).
*   **Ключевые результаты:** Выявлены несоответствия, предложены конкретные улучшения.
*   **Навыки:** Анализ требований, UI/UX, юзабилити.
*   [Анализ требований](https://github.com/Anastasiya-Kononova/QA-Portfolio/tree/c7b8a478279fb4bb4baa6a1916fab9d468918452/Анализ%20требований%20к%20мобильному%20приложению).

### 4. Тестирование поля "Дата рождения" и "Характеристика" (Тестовое задание)
*   **Описание:** Детальная проработка тестовых сценариев для сложных полей ввода с учетом классов эквивалентности, граничных значений и приоритезации.
*   **Ключевые результаты:** Спроектированы комплексные тестовые наборы для различных сценариев ввода.
*   **Навыки:** Тест-дизайн, работа с разными типами данных, приоритезация.
*   ["Дата рождения" и "Характеристика"](https://github.com/Anastasiya-Kononova/QA-Portfolio/tree/6ca812349f49dc077483a7c43c439e082121f323/Тестирование%20поля%20‘Дата%20рождения’%20и%20‘Характеристика’).

### 5. Анализ текстов интерфейса и предложение улучшений
*   **Описание:** Детальный анализ текстов интерфейса на наличие опечаток, грамматических ошибок, несоответствий локализации и контента.
*   **Ключевые результаты:** Предложены конкретные исправления с обоснованиями.
*   **Навыки:** Внимание к деталям, локализация, грамотность.
*   [Анализ текстов интерфейса](https://github.com/Anastasiya-Kononova/QA-Portfolio/tree/c7b8a478279fb4bb4baa6a1916fab9d468918452/Анализ%20текстов%20интерфейса).

*   **Описание:** Тестирование REST API сервиса PetStore (`https://petstore.swagger.io/`) с использованием Postman.
